 Интернет-магазин на Spring Boot

Веб-приложение интернет-магазина с авторизацией, корзиной и оформлением заказов.

Технологии
- Java 25
- Spring Boot 4.0.6
- Spring Security
- Spring Data JPA
- Liquibase
- H2 Database
- Thymeleaf
- Gradle
